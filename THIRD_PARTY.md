# Third-party components

Versions are resolved and should be recorded from the final tested environment
before submission.

| Component | Source | License | Use |
| --- | --- | --- | --- |
| Python | https://www.python.org/ | PSF License | Runtime |
| OpenCV | https://opencv.org/ | Apache-2.0 (current 4.x releases) | Video I/O and rendering |
| RapidOCR | https://github.com/RapidAI/RapidOCR | Apache-2.0 | Local OCR and packaged model files |
| ONNX Runtime | https://github.com/microsoft/onnxruntime | MIT | Local model inference runtime |
| NumPy | https://numpy.org/ | BSD-3-Clause | Image arrays |
| PyYAML | https://pyyaml.org/ | MIT | Context configuration |
| pytest | https://pytest.org/ | MIT | Tests only |

No third-party demo footage or datasets are included. RapidOCR model files are
installed as package dependencies and require final version/license review
before competition submission. The demo video is generated by this repository
from synthetic text.
