# Third-party components

Versions below are the ones installed by `pip install -r requirements.txt` in
the tested environment (Ubuntu 20.04, Python 3.8.10) on 2026-10-10. None of
these components are redistributed in this repository; pip installs them.

## Pretrained models

Shipped inside `rapidocr-onnxruntime` 1.4.4 as ONNX conversions of PaddleOCR
models (https://github.com/PaddlePaddle/PaddleOCR, Apache-2.0):

| File | Model | Use |
| --- | --- | --- |
| `ch_PP-OCRv4_det_infer.onnx` | PP-OCRv4 text detection | Find text regions |
| `ch_PP-OCRv4_rec_infer.onnx` | PP-OCRv4 text recognition | Read text |
| `ch_ppocr_mobile_v2.0_cls_infer.onnx` | PP-OCR v2.0 direction classifier | Text orientation |

## Language model runtime and weights

Not installed by pip. Users install Ollama and pull the model themselves.

| Component | Version tested | Source | License | Use |
| --- | --- | --- | --- | --- |
| Ollama | 0.40.2 | https://github.com/ollama/ollama | MIT | Local model server (Ollama-compatible API) |
| Qwen3-4B-Instruct (`qwen3:4b-instruct`, Q4_K_M) | Ollama library tag | https://github.com/QwenLM/Qwen3 | Apache-2.0 | Default context classifier |
| Llama 3.2 3B and 1B Instruct (`llama3.2:3b`, `llama3.2:1b`) | Ollama library tags | https://www.llama.com/ | Llama 3.2 Community License | Compared in `scripts/eval_context.py` only |
| Qwen3 1.7B, Qwen2.5 1.5B Instruct | Ollama library tags | https://github.com/QwenLM | Apache-2.0 | Compared in `scripts/eval_context.py` only |

The default model is Apache-2.0. The Llama models were only used for the
comparison and are not needed to run PrivacyLens.

## Data
